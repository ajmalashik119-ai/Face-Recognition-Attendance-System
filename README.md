# Face Recognition Attendance System 🎯

An automated attendance management system that uses **Facial Recognition** to identify students and record their attendance. Developed as a team project for our campus exhibition.

## 🚀 Project Overview

The Face Recognition Attendance System aims to simplify traditional attendance-taking by using computer vision. Instead of manually marking attendance, the system identifies registered faces and records attendance automatically.

To improve reliability, the system also uses **MediaPipe-based blink detection** as a basic liveness check to help prevent attendance using static photos.

## ✨ Key Features

- 👤 **Face Recognition** – Identifies registered individuals using facial recognition.
- 👁️ **Blink Detection** – Uses MediaPipe to detect eye blinking.
- 📋 **Automated Attendance** – Records attendance without manual input.
- 🗄️ **Database Integration** – Stores student information and attendance records.
- ⚡ **Real-Time Processing** – Processes camera input to recognize faces.

## 🛠️ Technologies Used

| Technology | Purpose |
|---|---|
| Python 3.12 | Core application |
| OpenCV | Image processing and face recognition |
| MediaPipe | Blink detection |
| PHP | Backend integration |
| MySQL | Database management |

## ⚙️ System Workflow

1. The camera captures the student's face.
2. The system processes the captured image.
3. Facial recognition checks the registered student data.
4. MediaPipe detects blinking as a basic liveness check.
5. Once verified, attendance is recorded in the database.
